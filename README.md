# Krishi Market – Farmer to Consumer Platform
# Project Overview
Krishi Market is a full-stack web application that connects farmers directly with consumers. It eliminates intermediaries and ensures fair pricing, better income for farmers, and fresh produce for customers.

# Features

*  Add agricultural products
*  View product listings
*  Direct farmer-to-consumer connection
*  Data stored in MongoDB
*  Simple and user-friendly interface

##  Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB

##  How to Run the Project

1. Install dependencies:
   npm install

2. Start backend server:
   node backend/server.js

3. Open frontend:
   frontend/index.html

##  API Endpoints

* **GET**
  http://localhost:5000/api/products

* **POST**
  http://localhost:5000/api/products

# Output

* Products can be added successfully
* Data is stored in MongoDB
* Products are displayed dynamically in UI
